# All Time Ecotour

Site de expedições com saída do Rio de Janeiro, adaptado para computador e celular.

## Visualizar

Abra `index.html` em um navegador. Não é necessário instalar dependências ou executar uma compilação. Imagens, estilos e JavaScript estão incorporados ao HTML. A fonte Red Hat Display é carregada pelo Google Fonts, com Arial como alternativa.

## Conteúdo

- Expedições internacionais, nacionais e terrestres.
- Galeria de fotos de clientes.
- História, missão, visão e valores.
- Informações de reserva e perguntas frequentes.
- Botões de atendimento direcionados ao WhatsApp da All Time.

## Hospedagem

Publique o arquivo `index.html` na raiz da hospedagem escolhida. A pasta também pode ser usada com GitHub Pages, quando esse recurso estiver disponível e for habilitado no repositório. O arquivo `.nojekyll` permite servir o conteúdo estático diretamente.

Para atualizar a página, substitua `index.html` pela nova versão aprovada.
